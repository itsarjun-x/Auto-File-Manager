# 📁 Auto File Manager

A clean, intuitive **Windows file organizer app** built in **Python (Tkinter)**.  
Automatically sorts your messy folders into categorized directories such as **Images**, **Documents**, **Audio**, **Videos**, and more — with one click.

---

### 💾 Download EXE (Windows)
You can directly download the latest `.exe` version from the [Releases Page](https://github.com/itsarjun-x/Auto-File-Manager/releases).

---

## ✨ Features

✅ Organizes files by type automatically  
✅ Clean and modern GUI using Tkinter  
✅ Custom app icon (`.ico`) and responsive layout  
✅ Works offline — no setup needed after build  
✅ Compatible with **Windows .exe** (PyInstaller ready)

---

## 🧠 Supported File Categories

| Category | Extensions |
|-----------|-------------|
| 🖼️ **Images** | `.jpg`, `.jpeg`, `.png`, `.gif`, `.bmp` |
| 📄 **Documents** | `.pdf`, `.docx`, `.doc`, `.txt`, `.pptx` |
| 🎵 **Audio** | `.mp3`, `.wav`, `.flac` |
| 🎬 **Video** | `.mp4`, `.mov`, `.avi` |
| 📦 **Archives** | `.zip`, `.tar`, `.gz`, `.rar` |
| 📂 **Others** | Everything else |
